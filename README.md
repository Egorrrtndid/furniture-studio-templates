# Furniture website templates

Two buildless HTML/CSS/JavaScript templates. Open `index.html` for the Ukrainian FORMA concept or `english.html` for the English OAK & FORM concept. Serve the directory through any static hosting provider. There are no package dependencies or API keys.

Both brands are fictional demonstration identities. All three interior photographs are AI-generated concept visualizations, not completed client projects. No testimonials or business statistics are represented. Budget ranges are illustrative inquiry options, not price quotations.

## Customization

Edit the chosen HTML page for branding, headings, descriptions, navigation, FAQ, and inquiry options. The JSON in `#site-data` supplies project dialog labels, material descriptions, and inquiry text. Keep its values aligned with the visible HTML. Colors and responsive layouts are in `style.css`. Interactions are in `app.js`.

Replace `living.png`, `kitchen.png`, and `dining.png` with licensed client imagery and update alt text. Replace the demo disclosures with truthful business information when adapting the template for an actual business. Set the title, description, and favicon. Remove the alternate-template links if deploying only one language. Enable indexing only after the business has approved its content.

## Inquiry form

The two-step form validates required fields and email. The English version validates US ZIP / ZIP+4. It previews an inquiry which can be copied or downloaded. It does not submit, store, or email personal information. Connect a real delivery endpoint and verify successful delivery before presenting the form as a working lead intake system. The visible demo notice explains this behavior.

## Included interactions

- Responsive menu and anchor navigation
- Project category filters and accessible native dialog previews
- Material palette selection with changing description and illustrative surface
- Two-step inquiry preview, copy, and download
- FAQ disclosures and reduced-motion support

The local Manrope font is covered by `manrope-license.txt`. Serif headings use the system Georgia font.

## Image generation

Generated with the built-in ImageGen tool. Full prompts are retained in `image-prompts.txt`.
